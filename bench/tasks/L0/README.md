# L0 — Knowledge Primitives Task Suite

> **Layer 0** of QuantAgentBench v3 reference implementation.
> Single-turn knowledge Q&A. No NPC, no persona, no sandbox.

## Generation

Generated by [bench/scripts/extract_l0_tasks.py](../../scripts/extract_l0_tasks.py).
Direct extraction from `data/01_structured/classified/` with quality + domain
filters. **No LLM calls** — pure rule-based selection.

The legacy synthesis path (`bench/scripts/synthesize_tasks.py` → adds tutoring
metadata) is deprecated for v3.

## Schema

Each task JSON conforms to the v3 single-turn schema:

```json
{
  "task_id": "L0_<source>_<source_id>",
  "version": "3.0",
  "layer": "L0",
  "category": "multi_step_reasoning | data_interpretation | conceptual_qa",
  "task_type": "single_turn",
  "requires_tool": false,
  "question": "...",
  "reference_answer": "...",
  "context": "...",
  "conversation_history": [...],
  "title": "...",
  "source_dataset": "finqa | convfinqa | tatqa | fiqa | money.stackexchange | finra | sec_investor_gov",
  "source_id": "<original record id>",
  "tags": [...]
}
```

`context` is required for `multi_step_reasoning` and `data_interpretation`
(financial reports / tables that the question references). Optional/null for
`conceptual_qa`.

`conversation_history` exists only for convfinqa records (multi-turn
financial reasoning where prior turns are part of the context).

## Out of v3 reference scope

The legacy Layer 1 categories `code_generation` / `code_debugging` /
`strategy_explanation` are **not** included in L0 v3. Code/execution skills
are covered at L1 (sandbox + tools, no NPC); strategy explanation surfaces in
L1/L2 task narratives. L0 focuses on pure knowledge primitives.

## Regeneration

Idempotent. Re-run with the same seed to reproduce; change `SEED` in
`extract_l0_tasks.py` to resample.

```bash
python bench/scripts/extract_l0_tasks.py
```

The script clears existing task JSONs in each category subdir before writing,
so the output is always a clean snapshot of the current plan.

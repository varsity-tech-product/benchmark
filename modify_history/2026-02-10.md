# Modification Log - 2026-02-10

## Summary

Production reliability fixes for LLM utilities, model testing and quality evaluation across 14 models, truncation fix, emotional_context optimization, and automatic model selection by dataset complexity.

## Changes

### 1. LLM Reliability Fixes (`scripts/lib/llm_utils.py`)
- **Network error retries**: Added `aiohttp.ClientError`, `asyncio.TimeoutError`, `ConnectionError` to tenacity retry decorator
- **Request timeout**: Added 120s timeout via `aiohttp.ClientTimeout(total=120)`
- **Defensive JSON parsing**: Guarded `response.json()` and `data["choices"]` access with try/except, raising `ServerError` for retries
- **Broader retry scope**: `call_llm_with_json` now catches `Exception` instead of just `LLMError` on parse retries
- **`strict_model` parameter**: Added to `call_llm_with_json()` to disable model fallback during per-model testing

### 2. Model Testing & Selection (`scripts/03_synthesize/synthesize_tsr.py`)
- **`--model` CLI flag**: Supports single model (strict) or comma-separated list (random selection per call)
- **`profile_model` / `strategy_model` tracking**: New fields populated alongside existing `teacher_model`
- **Failure logging**: Writes `{dataset}.failures.jsonl` on errors with source_id, model, error type/message
- **Auto model selection by dataset**: When no `--model` is provided, automatically selects from:
  - **Complex** (convfinqa, finqa, tatqa): `openai/gpt-5.2`, `anthropic/claude-sonnet-4.5`, `google/gemini-3-flash-preview`, `openai/gpt-oss-120b`
  - **Simple** (reddit, fiqa, stack_exchange, authoritative_docs): `google/gemini-3-flash-preview`, `openai/gpt-oss-120b`, `deepseek/deepseek-v3.2`, `deepseek/deepseek-chat-v3.1`

### 3. Truncation Fix
- **`max_tokens`**: Increased from 2048 to 3072 for response generation (`synthesize_tsr.py:301`)
- **Word limit prompt**: Added "Keep your response between 300-800 words" to both `response_generation_prompt` and `numerical_response_generation_prompt` in `configs/prompts.yaml`

### 4. emotional_context Optimization (`synthesize_tsr.py:203-206`)
- Force `emotional_context = None` for numerical reasoning records (convfinqa, finqa, tatqa) after profile generation
- These records are mechanical calculations where emotional context is always fabricated noise

### 5. Schema Update (`scripts/lib/schemas.py`)
- Added `profile_model: Optional[str]` and `strategy_model: Optional[str]` fields to `FinalBenchmarkRecord`

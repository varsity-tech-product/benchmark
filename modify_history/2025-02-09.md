# Modification Log - 2025-02-09

## Summary

Major updates to the synthesis pipeline, LLM utilities, cost estimation, and new data classification/quality inspection scripts.

## Changes

### 1. Synthesis Pipeline (`scripts/03_synthesize/synthesize_tsr.py`)
- **Classified data input**: Changed input source from `data/01_structured/` to `data/01_structured/classified/`, processing per-dataset files individually
- **Multi-model random selection**: Replaced hardcoded single model (`grok-4.1-fast`) with random selection from 10 diverse models per API call
- **New CLI interface**: Added mutually exclusive `--all`, `--dataset NAME`, `--list` flags for dataset selection
- **Per-dataset output**: Output is now split into per-dataset JSONL files (e.g., `stack_exchange.jsonl`) instead of a single `synthesized_data.jsonl`
- **Renamed `--output` to `--output-dir`**: Now accepts a directory instead of a single file path
- **Robust JSON normalization**: Added `_normalize_string_list()` to handle models returning dicts instead of plain strings in list fields
- **Whitespace cleanup**: Added regex-based cleanup for excessive whitespace in model responses

### 2. LLM Utilities (`scripts/lib/llm_utils.py`)
- **Expanded model pool**: Updated from 4 models to 10 models (LITE tier) with a commented-out FULL tier configuration
- **ServerError handling**: Added new `ServerError` exception class with retry support for 5xx HTTP errors
- **Robust JSON extraction**: Replaced simple markdown-stripping with `_extract_json()` function that handles reasoning leakage, nested braces, and edge cases
- **Retry with model fallback**: `call_llm_with_json()` now retries with different models on parse failure (attempt 0: requested model, attempt 1: random, attempt 2: fallback to `claude-sonnet-4.5`)
- **Increased token limit**: Raised `max_tokens` from default to 4096 for JSON responses to prevent truncation
- **Fallback model**: Added `FALLBACK_MODEL` constant (`anthropic/claude-sonnet-4.5`) for reliable structured output

### 3. Cost Estimation (`scripts/estimate_cost.py`)
- **Updated for new synthesis CLI**: Added `--all` flag and changed `--output` to `--output-dir` in subprocess call
- **Accurate record counting**: Now counts actual synthesized records across all per-dataset output files
- **Updated default total**: Changed default total records from 212,503 to 119,441
- **Directory cleanup**: Uses `shutil.rmtree` for temp directory cleanup instead of single file unlink

### 4. New Scripts
- **`scripts/02_structure/classify_data.py`**: Classifies structured records into 7 categories (reddit, fiqa, authoritative_docs, stack_exchange, finqa, tatqa, convfinqa) by `source_dataset` field
- **`scripts/02_structure/inspect_quality.py`**: General-purpose quality inspection for any StructuredQA JSONL file (statistics, quality flags, scoring)
- **`scripts/02_structure/inspect_reddit_quality.py`**: Reddit-specific quality analysis with subreddit distribution and tailored recommendations

### 5. New Evaluation System (`eval/`)
- Complete evaluation framework with automated scoring, LLM-as-judge, ablation studies, and experiment comparison
- Separate `requirements.txt` and `pyproject.toml`
- Langfuse tracing integration for observability

### 6. Documentation
- **README.md**: Updated to reflect new classification step, revised synthesis CLI, cost estimation tool, quality inspection scripts, and updated project structure
- **README_new.md**: Comprehensive project specification document (QuantTutorBench)
